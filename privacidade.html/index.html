Política de Privacidade

Esta política descreve como o AnhangueraCampinasContentAuto utiliza dados obtidos através da API do TikTok. O aplicativo acessa exclusivamente a conta oficial do Polo Anhanguera Campinas no TikTok, com autorização explícita do administrador dessa conta, para fins de publicação automatizada de conteúdo institucional previamente aprovado.

Não coletamos, armazenamos ou compartilhamos dados pessoais de terceiros através dessa integração. Os dados de autenticação (tokens de acesso) são armazenados de forma segura e usados exclusivamente para a função de publicação de conteúdo.

Para dúvidas sobre esta política, entre em contato pelo e-mail gregory.m.silva@parceiro-kroton.com.br.
